# 🌸 IRIS ANN - Iris Flower Classification using Artificial Neural Network

## 📌 Project Overview
This project builds an **Artificial Neural Network (ANN)** to classify Iris flowers into 3 species:
1. **Setosa**
2. **Versicolor**
3. **Virginica**

Based on 4 features: Sepal Length, Sepal Width, Petal Length, Petal Width.

This project is built from scratch for beginners to understand how ANN works on tabular data.

## 📊 Dataset
- **Name:** Iris Dataset (Fisher's Iris)
- **Rows:** 150
- **Features:** 4
- **Target:** 3 Classes
- **Source:** Sklearn / UCI Machine Learning Repository

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** TensorFlow, Keras, Pandas, Numpy, Matplotlib, Seaborn, Scikit-learn
- **Environment:** Google Colab / Jupyter Notebook

## 🧠 Model Architecture
ANN - Multilayer Perceptron (MLP)

- **Input Layer:** 4 neurons (4 features)
- **Hidden Layer 1:** 16 neurons (ReLU)
- **Hidden Layer 2:** 8 neurons (ReLU)
- **Output Layer:** 3 neurons (Softmax)

**Optimizer:** Adam
**Loss:** Sparse Categorical Crossentropy
**Epochs:** 100

## 🔄 Steps Followed
1. Load & Explore Data
2. Data Visualization (Pairplot, Heatmap, Countplot)
3. Train-Test Split (80-20)
4. Feature Scaling (StandardScaler)
5. Build ANN Model
6. Train Model
7. Evaluate Accuracy & Confusion Matrix

## 📈 Result
Achieved **~97% Accuracy** on Test Data.
